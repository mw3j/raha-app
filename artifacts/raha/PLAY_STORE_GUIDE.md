# دليل نشر تطبيق راحة على متجر Google Play

## المتطلبات الأساسية
- حساب Google Play Developer (رسوم لمرة واحدة: **25$**)
- حساب GitHub لتشغيل سير عمل البناء التلقائي

---

## الخطوة 1: إعداد حساب مطوّر Google Play

1. اذهب إلى: https://play.google.com/console
2. سجّل الدخول بحساب Google
3. ادفع 25$ رسوم التسجيل (مرة واحدة فقط)
4. أكمل بيانات المطوّر (الاسم، البلد، البريد الإلكتروني)

---

## الخطوة 2: إعداد GitHub Secrets

اذهب إلى مستودع GitHub الخاص بك:
**Settings → Secrets and variables → Actions → New repository secret**

أضف هذه الأسرار:

| الاسم | القيمة |
|-------|--------|
| `ANDROID_KEYSTORE` | (انظر الخطوة التالية) |
| `KEYSTORE_PASSWORD` | `raha@2026Secure` |
| `KEY_ALIAS` | `raha_key` |
| `KEY_PASSWORD` | `raha@2026Secure` |
| `VITE_API_URL` | `https://your-api-domain.com` |

### قيمة ANDROID_KEYSTORE:

**مهم جداً:** ملف التوقيع (keystore) مُولَّد مسبقاً لهذا التطبيق.
الكود المرمّز (Base64) محفوظ في `/tmp/keystore-b64.txt` على خادم Replit.

للحصول على القيمة، شغّل في طرفية Replit:
```bash
cat /tmp/keystore-b64.txt
```
ثم انسخ النص كاملاً والصقه كـ Secret بالاسم `ANDROID_KEYSTORE`.

---

## الخطوة 3: بناء التطبيق (AAB للمتجر)

### الطريقة التلقائية (GitHub Actions) - موصى بها:
1. اذهب إلى GitHub → **Actions** → **Build Release AAB (Play Store)**
2. اضغط **Run workflow**
3. أدخل:
   - **Version Code**: رقم الإصدار (يبدأ من 1، ويزيد مع كل إصدار جديد)
   - **Version Name**: اسم الإصدار (مثل: 1.0.0)
4. انتظر 5-10 دقائق حتى ينتهي البناء
5. حمّل ملف **raha-release-aab** من قسم Artifacts

---

## الخطوة 4: إنشاء التطبيق في Play Console

1. اذهب إلى: https://play.google.com/console
2. اضغط **إنشاء تطبيق**
3. أدخل:
   - **اسم التطبيق**: راحة - تطبيق إسلامي
   - **اللغة الافتراضية**: العربية
   - **نوع التطبيق**: تطبيق
   - **مجاني/مدفوع**: مجاني
4. وافق على السياسات واضغط إنشاء

---

## الخطوة 5: ملء معلومات المتجر

### الوصف المقترح:
```
تطبيق راحة - رفيقك الإسلامي اليومي

✨ المميزات:
• تصفّح القرآن الكريم مع التفسير والبحث
• أوقات الصلاة بدقة حسب موقعك مع الإشعارات
• الأذكار الصباحية والمسائية وأذكار متنوعة
• مسبحة رقمية تفاعلية
• قبلة رقمية بالبوصلة
• مكتبة إسلامية شاملة
• منتدى اجتماعي للمحتوى الإسلامي
```

### تصنيف التطبيق:
- **الفئة**: نمط الحياة أو التعليم
- **التقييم العمري**: للجميع (PEGI 3 / Everyone)

---

## الخطوة 6: رفع ملف AAB

1. في Play Console → **الإصدار** → **الإنتاج**
2. اضغط **إنشاء إصدار جديد**
3. ارفع ملف `.aab` الذي نزّلته من GitHub Actions
4. أضف ملاحظات الإصدار (مثل: "الإصدار الأول من تطبيق راحة")
5. اضغط **حفظ** ثم **المراجعة والنشر**

---

## الخطوة 7: المراجعة والنشر

- تستغرق مراجعة Google من **1 إلى 7 أيام** للتطبيقات الجديدة
- ستصلك رسالة بريد إلكتروني عند الموافقة أو رفض التطبيق
- بعد الموافقة، يظهر التطبيق في المتجر خلال ساعات

---

## ملاحظات مهمة

### حفظ ملف التوقيع:
⚠️ **احتفظ بملف التوقيع وكلمة المرور في مكان آمن!**
إذا فقدته، لن تستطيع تحديث التطبيق مستقبلاً.

### رابط التطبيق بعد النشر:
```
https://play.google.com/store/apps/details?id=com.raha.islamic
```

### تحديث الإصدارات:
في كل تحديث جديد، **يجب رفع versionCode** (مثلاً من 1 إلى 2)
ثم رفع ملف AAB الجديد في Play Console.
